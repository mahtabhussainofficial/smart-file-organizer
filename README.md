<h2>📌 Project Structure</h2>
<pre><code>├── README.md              # Project documentation
├── SMART_ORGANIZER.py     # Main Python script for file sorting and organization
└── organizer_activity.txt # Text log file recording organized files and operations</code></pre>

<hr />

<h2>⚡ Key Features</h2>

<table>
  <tr>
    <th>Feature</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><b>📁 Automatic Categorization</b></td>
    <td>Extension-based file sorting (e.g., Documents, Images, Videos, Archives).</td>
  </tr>
  <tr>
    <td><b>📝 Activity Logging</b></td>
    <td>Tracks all file movement and operations inside <code>organizer_activity.txt</code>.</td>
  </tr>
  <tr>
    <td><b>⚡ Lightweight & Fast</b></td>
    <td>Uses built-in Python modules (<code>os</code>, <code>shutil</code>) for high execution speed.</td>
  </tr>
</table>

<h2>🚀 How to Run</h2>

<h3>1. Repository Clone Karein</h3>
<pre><code>git clone https://github.com/mahtabhussainofficial/smart-file-organizer.git
cd smart-file-organizer</code></pre>

<h3>2. Script Run Karein</h3>
<pre><code>python SMART_ORGANIZER.py</code></pre>

<h3>3. Activity Log Check Karein</h3>
<p>Execution ke baad <b><code>organizer_activity.txt</code></b> open karke processed files ki details verify kar sakte hain.</p>
